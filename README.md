# PEAKFIT — Фитнес-клуб нового уровня

Одностраничный сайт для фитнес-клуба PEAKFIT. Светлая тема, анимации при скролле в стиле Apple, параллакс-эффекты на основе Framer Motion.

## Стек

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** — все анимации и параллакс
- **Lucide React** — иконки

## Структура страницы

| Секция | Описание |
|---|---|
| Navbar | Фиксированный, становится непрозрачным при скролле |
| Hero | Параллакс фон, коллаж из 2 фото справа |
| Stats | Анимированные счётчики при появлении в viewport |
| About | Параллакс на фото, вертикальная акцентная линия |
| Services | 6 карточек с hover-эффектами |
| ScrollTransform | Sticky-секция: 3 слайда меняются при скролле (СИЛА / СКОРОСТЬ / ФОРМА) |
| Trainers | Карточки тренеров с overlay и рейтингами |
| Gallery | Mosaic grid с параллаксом и lightbox |
| Pricing | 3 тарифных плана |
| CTA | Форма записи с параллакс-фоном |
| Footer | Контакты, навигация, соцсети |

## Запуск

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000)

## Сборка

```bash
npm run build
npm run start
```
